# 01 — Base Ideas

**Role:** epoch-bound Research workspace  
**State:** OPEN  
**Authority:** research material only; not maintained Product or Knowledge truth

## Research focus

Explore `newsflow` as a durable observation gateway between changing public internet sources and later agent or repository workflows.

Initial concerns include:

- discovery through APIs, RSS/Atom, sitemaps, publication calendars, index pages, and bounded HTML observation;
- source retrieval, timestamps, HTTP metadata, hashes, fingerprints, and change/revision detection;
- distinguishing a new publication from a changed or near-duplicate publication;
- source availability and disappearance;
- raw HTML or other representations only where technically and legally appropriate;
- event/inbox patterns that let agents start from detected changes instead of repeating web discovery;
- qualification and routing of primary-source candidates toward systems such as Tabularium without automatic admission;
- keeping source, representation, observation, derivation, and analytical claim separate;
- deciding which functions should remain deterministic automation and which genuinely require an agent or model.

## Working posture

These are research questions and hypotheses, not accepted design decisions.

Prefer small source-specific experiments and reproducible observations over premature universal crawlers, schemas, or taxonomies. Preserve provenance and explicit uncertainty whenever a candidate mechanism is evaluated.
