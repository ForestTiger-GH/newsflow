# newsflow

`newsflow` is a public-web observation and source-discovery workspace for building durable, agent-readable flows from changing internet sources.

The repository is intended to explore and later support source discovery, retrieval, change detection, provenance capture, event routing, and agent handoff. It is not itself an analytical truth layer and does not automatically promote discovered material into other repositories.

## Routes

- `_mw/AGENTS.md` — Engineering Work workspace front door.
- `_mw/epochs/001-foundation/` — active first Development Epoch.
- `_mw/epochs/001-foundation/research/01-base-ideas/` — initial research on the concept, boundaries, and operating model.

## Current posture

The repository is in its foundation epoch. The immediate goal is to establish the smallest useful model for observing public web/news flows and turning them into stable, provenance-aware inputs for later agent work.

Potential downstream use may include routing qualified primary-source material toward systems such as Tabularium, but discovery, preservation, qualification, admission, derivation, and analysis remain distinct operations.
